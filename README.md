# 🤝 Mãos que Ajudam — Gestão de Doações e Campanhas

> Aplicação web desenvolvida em Flask para centralizar, gerenciar e divulgar campanhas de arrecadação e doações comunitárias.

---

## 🎯 Objetivo do Projeto

O **Mãos que Ajudam** nasceu para solucionar a falta de visibilidade e organização enfrentada por pequenas instituições e iniciativas comunitárias de doação. 

Os principais objetivos da aplicação são:
* **Centralização:** Registrar e categorizar campanhas de arrecadação em um único ponto de acesso.
* **Transparência:** Exibir o progresso e o resumo das doações recebidas de forma clara para os doadores.
* **Acessibilidade:** Disponibilizar uma interface simples e responsiva para cadastro e navegação entre projetos sociais.

---

## 🛠️ Tecnologias Utilizadas

A stack do projeto foi selecionada para garantir leveza no processamento back-end e facilidade de navegação no front-end:

| Camada | Tecnologia | Função no Projeto |
| :--- | :--- | :--- |
| **Back-end** | Python 3.x | Lógica de negócios e scripts de suporte |
| **Micro-framework** | Flask | Roteamento de URLs, controle de requisições HTTP e renderização |
| **Front-end** | HTML5 / CSS3 | Estruturação das telas e estilização visual das páginas |
| **Template Engine** | Jinja2 | Integração de dados dinâmicos do Python diretamente no HTML |
| **Controle de Versão** | Git & GitHub | Versionamento de código e hospedagem do repositório público |

---

## 📚 Aprendizados Consolidados

A construção do projeto permitiu consolidar diversos conceitos fundamentais de engenharia de software e desenvolvimento web:

* **Arquitetura de Aplicações Web com Flask:** Compreensão do ciclo de vida das requisições HTTP (`GET` e `POST`), gerenciamento de rotas e manipulação de formulários.
* **Organização de Projetos Python:** Estruturação de diretórios seguindo o padrão MVC/Flask (`/static` para recursos visuais, `/templates` para HTMLs e arquivos de suporte na raiz).
* **Renderização Dinâmica com Jinja2:** Passagem de variáveis do Python para o template HTML, além do uso de laços de repetição e estruturas condicionais no front-end.
* **Fluxo de Versionamento Git:** Domínio do ciclo essencial de desenvolvimento colaborativo (`git init`, `git add`, `git commit`, vinculação de remotos e `git push`), além da configuração segura de autenticação.
